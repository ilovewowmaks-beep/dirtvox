# Dirt Vox — грязный вокал в одну кнопку (VST3 для FL Studio)

Ставишь на инсерт с вокалом, включаешь трек, жмёшь **АНАЛИЗ + ОБРАБОТКА**. Плагин слушает ~6 секунд голоса
и сам выставляет громкость, срез низа, вырез «каши», присутствие, компрессор и де-эссер. Грязь крутишь сам: ручка **DIRT**.

## Цепочка

Trim → Low Cut (24 дБ/окт) → вырез каши 320 Гц → присутствие 3.8 кГц → компрессор (5:1, быстрый) →
**перегруз** (2x оверсэмплинг, параллельно, громкость выравнивается автоматически) → де-эссер (5.5 кГц) →
склеивающий компрессор → Output → мягкий клиппер (потолок −1 дБ).

| Ручка | Что делает |
|---|---|
| DIRT | Сила перегруза |
| MIX | Сколько грязи подмешать к чистому сигналу |
| TONE | Срез верха после перегруза (убирает «песок») |
| OUTPUT | Громкость на выходе |
| Характер | **Warm** — мягкая лампа, **Rage** — жёсткий асимметричный, **Blown** — разорванный динамик |
| TRIM, LOW CUT, MUD, PRESENCE, COMP, DE-ESS | Выставляет анализ, можно докрутить руками |

## Как получить плагин (сборка на GitHub, ничего ставить не нужно)

1. Зайди на github.com (нужен аккаунт) → **New repository** → имя `dirtvox` → **Create repository**.
2. На странице репозитория нажми **uploading an existing file** и перетащи **всё содержимое** папки `dirtvox`
   (включая папку `.github`) → **Commit changes**.
3. Вкладка **Actions** → сборка запустится сама (~10 минут). Когда появится зелёная галочка, открой её
   и внизу в **Artifacts** скачай `DirtVox-VST3-Windows`.
4. Распакуй архив. Папку `Dirt Vox.vst3` скопируй в `C:\Program Files\Common Files\VST3\`.
5. FL Studio → **Options → Manage plugins → Find installed plugins**. Плагин появится как **Dirt Vox**.
6. Микшер → инсерт с вокалом → слот → **Dirt Vox**.

## Калибровка под EsDeeKid

Настройки подобраны не на глаз, а по замерам акапелл и треков EsDeeKid (4 Raws, Rottweiler, Phantom).
Что показали измерения его вокала и к чему гонит кнопка:

| Параметр | Референс EsDeeKid | Выход Dirt Vox | |
|---|---|---|---|
| Громкость (RMS) | плотный, −11 дБ | −10.5 дБ | ✓ |
| Динамика (crest) | сжатый | 9.5 дБ | ✓ |
| Корпус / presence / яркость | −5 / −10 / −11 | −6 / −9 / −10 | ✓ |
| Сибилянты | −6.8 дБ | −6.9 дБ | ✓ |
| Воздух (верх) | тёмный | тёмный | ✓ |

Его голос в изоляции **не сильно искажён** — он динамичный, плотный, мид-ориентированный и скорее тёмный.
«Грязь» в треках — это агрессивная подача + сильная компрессия + посадка в бит + умеренная сатурация.
Поэтому кнопка по умолчанию делает: контроль низа, корпус вперёд, плотную компрессию под громкую посадку,
умеренный де-эссер и тёмный характер. Дисторшн — добавкой ручкой DIRT (по умолчанию 50%).

Демо «до/после» на реальной акапелле: [demo/AB_dry_then_dirtvox.mp3](demo/AB_dry_then_dirtvox.mp3)
(10 с сухого вокала, потом 10 с через Dirt Vox, выровнено по громкости).

## Как пользоваться

1. Поставь Dirt Vox на инсерт вокала (лучше первым в цепочке, после тюна, если он есть).
2. Нажми **АНАЛИЗ + ОБРАБОТКА** и включи воспроизведение места, где есть голос. Полоса заполнится за ~6 секунд вокала,
   паузы не считаются.
3. Ручки внизу выставятся сами. Дальше крути **DIRT**, **MIX** и характер по вкусу.
4. Если голос записан по-другому (другой куплет, другой микрофон), нажми анализ ещё раз.

## Для разработки (Linux/macOS)

```
cmake -B build -DDIRTVOX_TESTS=ON && cmake --build build -j
./build/DirtVoxTest_artefacts/Release/DirtVoxTest out/   # синтетический тест: анализ, уровни, THD, WAV
```
